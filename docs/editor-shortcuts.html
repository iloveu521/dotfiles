Alt+P 多选后直接输入替换

VS Code 的 Alt+P 现在只在 VSCodeVim 插入模式触发。先按 i 进入插入模式，再按 Alt+P 选择当前词的匹配项；此时已经处于插入模式，直接输入新词覆盖多选区，最后按 Esc 结束。不要在选区建立后再按 i 或 a。

i 进入插入模式→Alt+P 多选匹配项→直接输入新词→Esc 结束

如果需要替换当前文件或整个工作区的所有完整单词，也可用 VS Code 原生替换：Ctrl+H 当前文件，Ctrl+Shift+H 整个工作区；开启 Match Whole Word（全词匹配，ab 图标或 Alt+W） 后再全部替换，避免把更长单词的一部分也改掉。Neovim 的 Alt+P 来自 multicursor.nvim，两边机制不同。

Vim 原生速查

以下是 Vim 的常用命令组合，不是额外自定义映射。普通模式下先按操作符，再按范围或文本对象。

模式

Esc 普通模式 · i 光标前插入 · a 光标后插入 · v 字符选择 · V 行选择

移动

h j k l 左下上右 · w/b 下/上个词首 · e 词尾

行与文件

0 行首 · ^ 首个非空白 · $ 行尾 · gg/G 文件首/尾

操作符 × 范围

d 删除 · y 复制 · c 修改；如 dw 删到词尾，y$ 复制到行尾

单词文本对象

iw 单词本身 · aw 单词及空格 · ciw 修改词 · viw 选中词

整行与撤销

yy 复制行 · dd 删除行 · cc 修改行 · p 粘贴 · u/Ctrl+R 撤销/重做

搜索

/词 向后 · ?词 向前 · n/N 下/上一个 · * 搜当前完整单词

全文替换

:%s/旧/新/gc 全文件逐处确认；:%s/旧/新/g 全部直接替换

改单个词

ciw 删除当前词并进入插入模式；输入新词后 Esc 完成

没有找到匹配项
换个按键、动作名或中文别名试试。
